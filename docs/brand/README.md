# The mark: Multiview

Four screens of a multiview; the gaps between them form a Latin cross (the crossbar sits a third
of the way down). The top-right pane is the live screen, in the app's live orange.

| File | Use |
|---|---|
| `symbol.svg` | Main mark on light backgrounds (ink `#111010`, live `#fa4f00`) |
| `symbol-reversed.svg` | On dark backgrounds (bone `#f5f5f5`, live `#fa4f00`) |
| `symbol-black.svg`, `symbol-white.svg`, `symbol-mono-fa4f00.svg` | One colour: print, engraving, stamps |
| `symbol-small.svg`, `symbol-small-reversed.svg` | 16–32 px: wider gaps so the cross stays open |
| `app-icon.svg` | Source of `src-tauri/icons` (`npx tauri icon <1024 px PNG of it>`) |
| `favicon-tile.svg` | Source of `static/favicon.png` |

Colours: ink `#111010`, bone `#f5f5f5`, live `#fa4f00`.

Rules: keep the four panes and the gaps as drawn (the cross is the gaps); only the top-right pane is
orange; leave clear space around it at least the height of a top pane (about a third of the mark); below 32 px
use the small cut. Don't stretch it, recolour other panes, add outlines or shadows, or put the
light version on light backgrounds.

The wordmark and lockups come once the product name is settled.
